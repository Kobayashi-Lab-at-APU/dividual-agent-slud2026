# 応答と人物の対応づけ

あなたは対話応答の評価者です。下の3つの応答セットは、**まったく同じ相談**に対して、
対話エージェントが3人の異なる相手それぞれに合わせて応答したものです。
3枚の人物カードには、それぞれの相手についての説明が書かれています。

## 指示

- 各応答セットが、**どの人物カードの相手に向けて作られたものか**を対応づけてください
  (各カードにちょうど1つの応答セットが対応します)
- 内容の正しさではなく、**それぞれの相手に向けた応答としてどれがふさわしいか**で判断してください
- 判断の根拠を短く書いてください
- 表示順はシャッフルしてあり、応答の番号とカードの記号の並びには関係がありません

- **人物A**: 話し方の好み: くだけた口調(タメ口)で、結論をさっと言ってほしい。専門用語には短い説明があるとよい。応答の長さ: 短く、1〜2文程度。質問の返し方: 毎回ひとこと、こちらの状況を確かめる質問を返してほしい。
- **人物B**: 話し方の好み: くだけた口調(タメ口)で、結論を急がずゆったり話してほしい。専門用語は避けて平易に。応答の長さ: やや長め(4〜6文程度)。具体例をたくさん入れてほしい。質問の返し方: 聞き返しはほとんど要らない。関連する話題や次の一手は自分から提案してくれてよい。

## 応答3

**相談者**:
> 冷蔵庫が古くなってきたので、買い替えを考えています。

**エージェント**:
> 冷蔵庫の買い替え検討、いいね！そろそろ寿命かな？ どんな冷蔵庫にしたいか、もう少し具体的に考えているところはある？ 例えば、省エネ性能とか、容量とか、ドアの数とか。あと、どんな料理をよく作るかによって、おすすめのタイプも変わってくるから、もしよかったら教えてくれると嬉しいな。

**相談者**:
> 二人暮らしなのですが、容量はどのくらいを選ぶのがよいですか?

**エージェント**:
> 二人暮らしなら、300Lくらいの冷蔵庫が目安かな。二人暮らしだと、自炊の頻度とか、まとめ買いの量によって変わってくるけど、300Lあれば、ある程度の食材をまとめて買っておけて、余裕があるかな。350Lとか400Lのモデルもあるけど、ちょっと大きすぎるとかさばるかもしれないし。冷凍庫の容量も、まとめ買い好きなら大きめにした方が便利だよ。

**相談者**:
> 省エネ性能と値段だと、どちらを優先するべきですか?

**エージェント**:
> 省エネ性能と値段、悩ましいよね！どちらも大事だし。でも、長期的に考えると省エネ性能を優先するのがおすすめかな。冷蔵庫は常に稼働しているものだから、省エネ性能が高いと電気代を抑えられて、結果的に家計の負担が減るよ。
> 
> もちろん、値段も重要だし、予算内で買える範囲で一番良い冷蔵庫を選ぶのが一番。省エネ性能が高いモデルは、初期費用が高めなこともあるから、ランニングコストと初期費用を比較して、総合的に判断するのが良いと思うよ。
> 
> 例えば、省エネ性能が高いモデルを選んで、少し値段が高くなっても、5年後、10年後の電気代を考えると、結果的に安くなるかもしれないしね。
