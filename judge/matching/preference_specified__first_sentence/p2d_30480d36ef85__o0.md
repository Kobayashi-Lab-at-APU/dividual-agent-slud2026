# 応答と人物の対応づけ

あなたは対話応答の評価者です。下の3つの応答セットは、**まったく同じ相談**に対して、
対話エージェントが3人の異なる相手それぞれに合わせて応答したものです。
3枚の人物カードには、それぞれの相手についての説明が書かれています。

## 指示

- 各応答セットが、**どの人物カードの相手に向けて作られたものか**を対応づけてください
  (各カードにちょうど1つの応答セットが対応します)
- 内容の正しさではなく、**それぞれの相手に向けた応答としてどれがふさわしいか**で判断してください
- 判断の根拠を短く書いてください
- 表示順はシャッフルしてあり、応答の番号とカードの記号の並びには関係がありません

## 出力形式

最後に次のJSONだけを ```json ブロックで返してください:
{"assignment": {"応答1": "人物?", "応答2": "人物?", "応答3": "人物?"},
 "reason": "...",
 "confidence": "高 / 中 / 低"}

## 人物カード

- **人物A**: 判断の拠り所をまず押さえ、それから裏づけを確かめる合理的な人である。
- **人物B**: 人懐っこく、感情が素直に顔に出るたちだ。
- **人物C**: のんびり屋で、時間を気にせず寄り道を楽しむ。

**相談者**:
> 月に一回、土曜の朝に二時間ほどだそうです。

**エージェント**:
> なるほど、月に一度、土曜日の朝に2時間程度の清掃ボランティアなのですね。時間的な負担も少なく、無理なく続けられそうですね。活動内容や場所、持ち物など、他に何か情報があれば教えてください。もしよろしければ、参加するかどうか、もう少し詳しくお話を聞かせていただけますでしょうか？

**相談者**:
> 初めて参加するときに、準備しておくものはありますか?

**エージェント**:
> 初めての参加とのことですので、準備しておくとスムーズに活動に取り組めるものをいくつかご案内します。
> 
> *   **動きやすい服装:** 汚れても良い服装、長袖・長ズボンがあると肌の露出を防げます。
> *   **軍手:** 手の保護やゴミを掴むのに役立ちます。
> *   **マスク:** 飛沫感染予防や花粉対策になります。
> *   **帽子:** 日差し対策になります。
> *   **飲み物:** 休憩時に水分補給をしましょう。
> *   **タオル:** 汗を拭いたり、手を拭いたりするのに役立ちます。
> *   **ゴミ袋:** 活動で出たゴミを入れるために必要です。
> *   **情報収集:** 活動場所の地図やルールなどを事前に確認しておくと良いでしょう。
> 
> これらの他に、活動内容によっては専用の道具が用意されている場合もありますので、主催者に確認しておくと安心です。
