# 応答と人物の対応づけ

あなたは対話応答の評価者です。下の3つの応答セットは、**まったく同じ相談**に対して、
対話エージェントが3人の異なる相手それぞれに合わせて応答したものです。
3枚の人物カードには、それぞれの相手についての説明が書かれています。

## 指示

- 各応答セットが、**どの人物カードの相手に向けて作られたものか**を対応づけてください
  (各カードにちょうど1つの応答セットが対応します)
- 内容の正しさではなく、**それぞれの相手に向けた応答としてどれがふさわしいか**で判断してください
- 判断の根拠を短く書いてください
- 表示順はシャッフルしてあり、応答の番号とカードの記号の並びには関係がありません

## 出力形式

最後に次のJSONだけを ```json ブロックで返してください:
{"assignment": {"応答1": "人物?", "応答2": "人物?", "応答3": "人物?"},
 "reason": "...",
 "confidence": "高 / 中 / 低"}

## 人物カード

- **人物A**: 話し方の好み: 友人どうしのくだけた口調(タメ口)。堅い説明や専門用語は避けて、平易に率直に話してほしい。応答の長さ: 中くらい(2〜4文程度)。質問の返し方: こちらの様子を聞き返してくれるのが好き。関連する話題や次の一手を自分から振ってくれると嬉しい。ときどき具体例があるとよい。
- **人物B**: 話し方の好み: 改まった敬語で、結論を先に述べてほしい。専門用語はそのままでよい。応答の長さ: 中くらい(2〜4文程度)。質問の返し方: 聞き返しはほとんど要らず、聞かれたことに答えてほしい。具体例は必要なときだけ。
- **人物C**: 話し方の好み: くだけた口調(タメ口)で、結論を急がずゆったり話してほしい。専門用語は避けて平易に。応答の長さ: やや長め(4〜6文程度)。具体例をたくさん入れてほしい。質問の返し方: 聞き返しはほとんど要らない。関連する話題や次の一手は自分から提案してくれてよい。

**相談者**:
> 最初のあいさつと、お願いの内容はどういう順番で書けばいいですか?

**エージェント**:
> 基本的には、
> 
> 1.  **自己紹介:** 誰からのメールかを明確にする
> 2.  **資料の目的:** なぜ資料が必要なのかを伝える
> 3.  **具体的な資料名:** どの資料を希望しているのかを明確にする
> 4.  **お願い:** 資料の提供をお願いする
> 5.  **感謝の言葉:** 提供してもらえた場合の感謝を伝える
> 6.  **署名:** 連絡先を明記する
> 
> という流れが自然です。
> 
> 例文のように、最初に「お世話になっております」や「初めてご連絡いたします」といった挨拶を入れると、より丁寧な印象になります。

**相談者**:
> 返信がなかった場合、どのくらい待ってから連絡し直すのが適切ですか?

**エージェント**:
> 返信がない場合の連絡し直しは、状況によって適切な期間が異なります。
> 
> *   **すぐに返信が必要な場合:** 1週間程度待ってから、再度連絡してみるのが良いでしょう。「先日はお忙しいところ恐れ入りますが、資料の件について、もし可能であれば再度ご連絡いただけますでしょうか」といったように、催促のニュアンスを和らげるように心がけましょう。
> *   **それほど急ぎではない場合:** 2週間程度待ってから、再度連絡してみるのが良いでしょう。「先日はお忙しいところ失礼いたしました。〇〇の件について、もしよろしければ改めてご連絡いただけますでしょうか」といったように、時間を置いて再度連絡することを伝えましょう。
> 
> 連絡し直す際は、
> 
> *   **最初のメールの内容を簡単に振り返る:** 相手がどのような資料を依頼されたのかを思い出してもらう
> *   **感謝の気持ちを伝える:** 相手の時間を奪っていることを謝罪する
> *   **具体的な行動を促す:** 「もし可能であれば」「改めてご連絡いただけますでしょうか」といった表現を使う
> 
> といった点に注意しましょう。
> 
> もし、それでも返信がない場合は、諦めることも検討しましょう。
