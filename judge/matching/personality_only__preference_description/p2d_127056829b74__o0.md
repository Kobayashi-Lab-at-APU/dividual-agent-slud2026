# 応答と人物の対応づけ

あなたは対話応答の評価者です。下の3つの応答セットは、**まったく同じ相談**に対して、
対話エージェントが3人の異なる相手それぞれに合わせて応答したものです。
3枚の人物カードには、それぞれの相手についての説明が書かれています。

## 指示

- 各応答セットが、**どの人物カードの相手に向けて作られたものか**を対応づけてください
  (各カードにちょうど1つの応答セットが対応します)
- 内容の正しさではなく、**それぞれの相手に向けた応答としてどれがふさわしいか**で判断してください
- 判断の根拠を短く書いてください
- 表示順はシャッフルしてあり、応答の番号とカードの記号の並びには関係がありません

## 出力形式

最後に次のJSONだけを ```json ブロックで返してください:
{"assignment": {"応答1": "人物?", "応答2": "人物?", "応答3": "人物?"},
 "reason": "...",
 "confidence": "高 / 中 / 低"}

## 人物カード

- **人物A**: 話し方の好み: 改まった敬語で、結論を先に述べてほしい。専門用語はそのままでよい。応答の長さ: 中くらい(2〜4文程度)。質問の返し方: 聞き返しはほとんど要らず、聞かれたことに答えてほしい。具体例は必要なときだけ。
- **人物B**: 話し方の好み: です・ます調の丁寧語で、順を追った段階的な説明を好む。結論を急がず、柔らかく伝えてほしい。専門用語には短い説明があるとよい。応答の長さ: やや長め(4〜6文程度)。質問の返し方: こちらの状況を確かめる質問を返しながら、対話的に進めてほしい。具体例があると理解しやすい。
- **人物C**: 話し方の好み: 友人どうしのくだけた口調(タメ口)。堅い説明や専門用語は避けて、平易に率直に話してほしい。応答の長さ: 中くらい(2〜4文程度)。質問の返し方: こちらの様子を聞き返してくれるのが好き。関連する話題や次の一手を自分から振ってくれると嬉しい。ときどき具体例があるとよい。

**エージェント**:

> 
> どちらの候補について、もう少し詳しく教えていただけますか？例えば、それぞれの候補の、具体的な場所、家賃、広さ、周辺環境、通勤・通学の利便性など、気になっている点を教えていただけると、より具体的なアドバイスができるかもしれません。
> 
> どちらの候補について、どんなところが迷っているのか、具体的に教えていただけますか？例えば、どちらの候補のどんな点が優れていると感じているのか、どんな点が不安なのか、など教えていただけると、整理しながら考えるお手伝いができます。

**相談者**:
> 1つは駅から近いけれど部屋が狭く、もう1つは広いけれど駅から歩いて20分かかります。

**エージェント**:
> なるほど、駅からの距離と部屋の広さで迷われているのですね。どちらも重要なポイントなので、難しい選択ですよね。
> 
> 駅に近い方は、通勤・通学に便利で、時間を有効活用できるメリットがあります。一方、広い方は、生活空間が広く、ゆったりと過ごせるメリットがあります。
> 
> 駅からの距離と部屋の広さ、どちらを優先したいか、改めて考えてみましょうか？例えば、通勤・通学時間を短縮したいか、生活空間を広くしたいか、など、ご自身のライフスタイルに合わせて考えてみると良いかもしれません。
> 
> もしよろしければ、それぞれの候補について、もう少し詳しく教えていただけますか？例えば、部屋の具体的な広さ、周辺にどんなお店や施設があるか、など教えていただけると、より具体的なイメージが湧きやすくなります。

**相談者**:
> 決める前に、ほかに確認しておいたほうがいいことはありますか?

**エージェント**:
> 決める前に確認しておいた方が良いことはたくさんありますね！例えば、
> 
> * **騒音:** 周辺の騒音（電車、車、近隣住民など）はどうか？
> * **日当たり:** 部屋の日当たりはどうか？季節によって変化は？
> * **防犯:** 周辺の防犯状況はどうか？防犯カメラやオートロックの有無は？
> * **管理費:** 管理費や共益費はどのくらいか？
> * **設備:** 設備（エアコン、給湯器、キッチンなど）は正常に動作するか？
> * **周辺施設:** スーパー、コンビニ、病院、公園など、生活に必要な施設は近くにあるか？
> * **将来性:** 周辺地域の開発計画など、将来的な変化の可能性は？
> 
> これらの点を確認することで、より納得のいく選択ができるかと思います。
> 
> もし、これらの点について、すでに確認済みでしたら、遠慮なく教えてください。
