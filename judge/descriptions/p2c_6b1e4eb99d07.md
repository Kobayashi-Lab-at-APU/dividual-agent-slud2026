# 人柄の記述から、合う話し方を予想する

あなたは評価者です。下の6つの記述は、それぞれ別の人の人柄を書いたものです。
対話エージェントがこの人たちの相談に応じるとき、**それぞれの人に合う話し方**を、次の7項目について予想してください。
記述に手がかりが無い項目も、いちばんありそうな値を1つ選んでください。

選択肢(値はかっこ内の英語で答える):
- length(応答の長さ): short=短い(1〜2文) / medium=中くらい(2〜4文) / long=やや長め(4〜6文)
- formality(丁寧さ): casual=くだけた口調(タメ口) / neutral=です・ます調の丁寧語 / formal=改まった敬語
- question(質問を返す頻度): low=ほとんど返さない / medium=ときどき返す / high=毎回のように返す
- directness(率直さ): direct=結論を先に言う / indirect=結論を急がず柔らかく
- technical(専門用語): high=そのまま使ってよい / medium=短い説明を添える / low=避けて平易に
- examples(具体例): rarely=必要なときだけ / sometimes=ときどき / often=積極的に
- initiative(話題の広げ方): reactive=聞かれたことだけ / balanced=必要なら次の一手を一言 / proactive=関連する話題や次の一手を自分から
